# ข้อมูลอยู่ที่ไหน

- โปรแกรมและ runtime: โฟลเดอร์ที่ติดตั้งแอป
- Skill: โฟลเดอร์ skills ของ Codex/Claude ของผู้ใช้ OS คนนั้น
- ชุดฝึกและสถานะติดตั้ง: `.pngoung-capsule` ใน home ของผู้ใช้
- งานจริง: โฟลเดอร์ที่ผู้ใช้เลือก; `.capsule-state` เก็บ baseline, lineage และ journal ชั่วคราว
- ของส่งต่อ: ไฟล์ `.capsule` ในโฟลเดอร์ส่งต่อที่เลือก

ไฟล์ capsule เป็น JSON ที่อ่านและถอด base64 ได้ **ไม่ได้เข้ารหัส** เลือกช่องทางที่คุณเชื่อถือและมีสิทธิ์เข้าถึง อย่าใส่ secret, ข้อมูลลูกค้า หรือข้อมูลส่วนบุคคลที่ไม่จำเป็น ระบบตรวจรูปแบบค่าลับช่วยป้องกันบางกรณีแต่ตรวจความอ่อนไหวทุกชนิดไม่ได้

แอปไม่มี telemetry, ไม่มี model API call, ไม่เปิดพอร์ตสาธารณะ และไม่อัปโหลดงานเอง การเลือกโฟลเดอร์ที่มีบริการ sync อยู่จะส่งไฟล์ตามการตั้งค่าของบริการนั้น ส่วนข้อมูลที่ AI อ่านและส่งให้ผู้ให้บริการ AI เป็นไปตามบริการ/บัญชีที่ผู้ใช้เลือก

การติดตั้งอาจดาวน์โหลด Node จาก nodejs.org และโค้ดจาก GitHub เมื่อใช้ bootstrap; หลังติดตั้ง การสร้าง/รับ capsule และชุดฝึกทำงานในเครื่องได้ ไม่ต้องใช้ QMD หรือ API key

ถอนการติดตั้ง: ปิดแอป ตรวจ CAPSULE_APP.json ว่าเป็นชุดนี้ แล้วลบเฉพาะ skill pngoung-capsule ที่ตัวติดตั้งเป็นเจ้าของ ลบโฟลเดอร์แอปได้หลังสำรองงาน ชุดฝึกและโปรเจกต์จริงยังอยู่แยกกัน; ไม่มี autostart หรือระบบ SSH ให้ถอด
