# ฝึกส่งต่องานจนกลับมาปิดที่เดิม

## แบบฝึกในเครื่องเดียว

1. ติดตั้งแล้วเปิดหน้าเริ่มต้น คัดลอกข้อความให้ AI
2. ให้ AI รัน demo และเปิด work.md ของ device-a อ่านว่ามี draft, review, checklist ครบ
3. ตรวจว่า revision เป็น 4 และ status ของ capsule สุดท้ายเป็น final
4. อธิบายผลให้ได้ว่าเป็นการจำลองหลายโฟลเดอร์ในเครื่องเดียว

## ข้ามแชต / ข้าม AI

สร้างโปรเจกต์แผนงานหนึ่งหน้า เลือกส่งเฉพาะ plan.md ให้ AI ตัวแรกสร้าง capsule
เปิดแชตใหม่ใน AI อีกตัว รับเข้าโฟลเดอร์ใหม่ อ่านสรุป แล้วเพิ่ม checklist
ส่งกลับ ให้แชตแรกตรวจ inbox และรับรุ่นใหม่ก่อนทำต่อ เปรียบเทียบไฟล์จริง

## ข้าม Mac และ Windows

ใช้เครื่องทดสอบและบัญชีของผู้เรียนเอง ติดตั้งชุดเดียวกันทั้งสองเครื่อง เลือกโฟลเดอร์ส่งต่อที่แต่ละเครื่องเข้าถึงได้ หรือคัดลอกไฟล์ .capsule ด้วยตนเอง
ทำ A → B → C → A ตาม Skill (C อาจเป็นเครื่องที่สาม) แต่ละขาต้องจด packet ID ที่ผู้ส่งกับผู้รับเห็นและตรวจ hash ปลายทางตรงกัน
เปลี่ยนบัญชี AI บนเครื่องเดิมแล้วรับ capsule ด้วยบัญชีใหม่ ตรวจสิทธิ์อ่านไฟล์และ skill discovery ใหม่ ไม่สรุปว่าประวัติแชตเดิมย้ายตาม

## ทดสอบงานชนกัน

หลังส่ง ให้แก้ไฟล์เดียวกันทั้ง A และ B แล้วลองรับกลับ: ต้องเห็น conflict และไฟล์ A ต้องยังเหมือนเดิม รับ B เข้าโฟลเดอร์ใหม่เพื่อเทียบโดยไม่ทับงาน

## เกณฑ์ส่งงาน

- เปิดแชตใหม่แล้วบอกเป้าหมาย ข้อตัดสินใจ และงานค้างได้จากข้อมูลจริง
- รับไฟล์ล่าสุดได้พร้อม receipt และ checksum ปลายทาง
- เก็บไฟล์นอกขอบเขตไว้ครบ และไม่ส่งค่าลับ
- กลับ A แล้วตรวจและปิดงานได้
- ระบุ OS/Agent/account scenario ที่ทดลองจริง แยกจากสิ่งที่จำลอง
